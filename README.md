# RECOIL CLIMB

スマホブラウザ向けの「壺おじ系」2Dクライミングゲーム。ジャンプも歩きもない。**銃の反動だけ**で野原を越え、塔を登り、その上の空を目指す。ドット絵（PICO-8系パレット）。

テストプレイ: https://hyoshida.github.io/blame/ （`main` への push で自動更新）

## 遊び方

- 画面のどこでもドラッグして離すと、その向きに撃つ。反動で反対側へ飛ぶ
- 引っぱる長さで強さが変わる。狙っている間は軌道が表示され、空中では時間がかなりゆっくりになる
- はじめは空中で撃てない。道中の道具で能力が増える（頭上の点が残弾）
- 弾は着地か緑の結晶で回復。トゲに触れるとミスで、直前に立っていた足場に戻る
- 大きく落ちても死なない。落ちたところからやり直し（壺おじ仕様）
- 進行は自動セーブ（端末のブラウザ内）

### 道具（入手順）

| 道具 | 効果 | 使いどころ |
| --- | --- | --- |
| 予備弾倉 | 空中の弾 +1 | 野原の途中。直後にトゲの谷 |
| 砕岩弾 | ひび割れた岩を壊せる | 塔の下層。真上がひびの天井 |
| 予備弾倉 | 空中の弾 +1（計 2） | 氷エリアの上。直後に高い縦穴 |
| 貫通弾 | 弾がガラスを通る | 縦穴の上。ガラスに入った的 |
| 強装弾 | 反動が大きく強くなる | 頂上直下。届かなかった高さへ |

### 知っていると道が開けるもの（ネタバレ）

<details><summary>開く</summary>

- 結晶は**弾を当てても**補給できる（遠くからでも。狙うと結晶が光る）
- 赤い的を撃つと、近くの扉が開く
- 金属に当たった弾は跳ね返る
- 羽根は 5 枚。後で手に入る道具で取れるものもある（戻る価値あり）
- 頂上の天井のひびを壊すと、その上に「天国」がある

</details>

PC: マウスでドラッグ、Esc でポーズ。
デバッグ: URL 末尾に `#row60` を付けるとその行付近の足場から開始（それより下の道具は取得済み、0 が最上段）。`#at52,165` は指定タイルから開始。

## 開発

依存パッケージなし（Node 22）。

```sh
npm run build   # src/ を 1 ファイルに inline → dist/index.html
npm run solve   # ソルバーで道具の順に頂上・天国まで到達可能か検証（~3分。--full で羽根の回収も確認）
npm run serve   # dist をローカル配信
NODE_PATH=$(npm root -g) node tools/smoke.mjs   # ヘッドレスでスマホ表示のスモークテスト
```

| ファイル | 内容 |
| --- | --- |
| `src/level.js` | マップ（140×172 タイル）と看板の文言。座標指定で部屋を配置 |
| `src/physics.js` | 物理・弾の挙動・道具の効果。ゲームとソルバーで共有 |
| `src/game.js` | 描画・入力・音・セーブ |
| `tools/solve.mjs` | 到達可能性ソルバー（CI でも実行） |

調整しやすい数値は `src/physics.js` 冒頭の `C`（重力、反動、空中の弾数など）。数値やマップを変えたら `npm run solve` で到達できることを確認する。

`main` に push すると GitHub Actions がソルバー → ビルド → GitHub Pages へデプロイする（リポジトリ設定の Pages で Source を "GitHub Actions" にしておく）。
