# RECOIL CLIMB

スマホブラウザ向けの「壺おじ系」2Dクライミングゲーム。ジャンプはなく、**銃の反動だけ**で高難度の塔を登る。ドット絵（PICO-8系パレット）。

## 遊び方

- 左下の ◀ ▶ で歩く
- 画面を押してドラッグ → 離すと、その向きに発砲（設定で「タップした方向に即発砲」にも切替可）
- 撃つと反対方向に吹っ飛ぶ。下に撃てば上へ、空中で左に撃てば右へ
- 空中で撃てるのは 2 発。着地か緑の結晶で装填
- トゲに触れると弾かれて一瞬操作不能。死亡もチェックポイントもなし。落ちたらそこからやり直し
- 進行は自動セーブ（端末のブラウザ内）。「つづきから」で再開

PC: A/D か ←→ で移動、マウスで狙ってクリック（Space でも発砲）、Esc でポーズ。

デバッグ: URL の末尾に `#row60` のように付けると、その行付近から開始（0 が最上段、110 が最下段）。

## 開発

依存パッケージなし（Node 22）。

```sh
npm run build   # src/ を 1 ファイルに inline → dist/index.html
npm run solve   # 総当たりソルバーで頂上まで到達可能か検証（~40秒）
npm run serve   # dist をローカル配信
NODE_PATH=$(npm root -g) node tools/smoke.mjs   # ヘッドレスでスマホ表示のスモークテスト
```

| ファイル | 内容 |
| --- | --- |
| `src/level.js` | マップ（18×112 タイル、文字で記述） |
| `src/physics.js` | 物理と当たり判定。ゲームとソルバーで共有 |
| `src/game.js` | 描画・入力・音・セーブ |
| `tools/solve.mjs` | 到達可能性ソルバー（CI でも実行） |

調整しやすい数値は `src/physics.js` 冒頭の `C`（重力、反動、空中の弾数など）。数値やマップを変えたら `npm run solve` で頂上に届くことを確認する。

`main` に push すると GitHub Actions がソルバー → ビルド → GitHub Pages へデプロイする（リポジトリ設定の Pages で Source を "GitHub Actions" にする）。
